# Machine Learning Class

Class exercises and notes for machine learning.

- `notebooks/` and `lab_practice/`: Jupyter exercises.
- `lab_practices_KNN_changing_parameters/`: KNN and Naive Bayes labs.
- `scripts/`: Python practice scripts.
- `dataset/`: datasets; `outputs/`: saved results.

Run scripts from the project root (for example, `python scripts/lab_task_script.py`). Open notebooks with their working directory set to the notebook's folder. Some exercises require separately downloaded data or local path changes.

## Lab summaries

- [Simple linear regression](notebooks/simple_linear_regression.ipynb): Predicts a student's final mark from attendance hours.
- [Multiple linear regression](notebooks/lab_activity_linear_regression_multiple_features.ipynb): Predicts student productivity scores using several productivity and digital-distraction features.
- [Food delivery regression](notebooks/revised_regression_comparison_lab.ipynb): Predicts food delivery time using features such as distance, weather, and traffic, and compares regression models.
- [Ensemble methods](notebooks/Updated_Lab_Experiments_with_Ensemble_Methods%28Digits%29.ipynb): Classifies handwritten digits from 0 to 9 using combinations of classifiers.
- [KNN from scratch](lab_practice/Knn_implementation.ipynb): Predicts a sample's class using distance-weighted votes from its nearest neighbors. [KNN testing](lab_practice/knn_test.ipynb) explores different values of k.
- [KNN classification](lab_practices_KNN_changing_parameters/knn_for_classification.ipynb): Predicts a binary class from health and lifestyle data and compares custom and scikit-learn KNN models.
- [Naive Bayes](lab_practices_KNN_changing_parameters/Naive_Bayes_Correct_Code.ipynb): Predicts whether to play based on weather conditions such as outlook, temperature, humidity, and wind.
- [Decision tree](lab_practice/decisionTree.ipynb): Calculates Gini impurity to choose a feature for splitting high- and low-risk examples.
- [Weather time series](notebooks/Weather_TimeSeries.ipynb): Cleans and explores climate data and temperature patterns across locations, seasons, and time.
- [AI job market analysis](notebooks/LabPractice.ipynb): Explores AI job postings and compares salaries by job title, experience, and other factors.
- [Statistics practice](notebooks/statistics_practice_questions%20%281%29.ipynb): Practices identifying data types and visualizing programming-language preferences, quiz scores, and study hours.
